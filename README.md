##### **Refleksi**



1. Mengapa branch diperlukan?

&#x09;Branch diperlukan agar kita dapat mengembangkan atau mencoba fitur baru tanpa mengubah proyek utama. Dengan begitu, jika terjadi kesalahan, proyek utama tetap aman dan tidak terganggu.
2. Apa keuntungan bekerja pada branch dibanding langsung di main?
	Keuntungan bekerja pada branch adalah kita bisa mengembangkan fitur baru, memperbaiki bug, atau melakukan percobaan tanpa memengaruhi branch main. Jika hasilnya sudah sesuai, barulah perubahan tersebut digabungkan ke branch main.
3. Kapan sebaiknya membuat branch baru?
	Branch baru sebaiknya dibuat saat ingin menambahkan fitur baru, memperbaiki kesalahan (bug), atau mencoba perubahan pada proyek. Setelah perubahan selesai dan sudah dipastikan benar, branch tersebut dapat digabungkan ke branch main.
